# Anti Radar: Portfolio Pulse demo script (2:38)

The tour lives at `/demo/portfolio`. It opens Portfolio Pulse, follows one company through a material event and its competitive map, hands a performance claim to the existing technical diligence workspace, reads the portfolio brief, and ends on the agent that wrote the brief and its own failure ledger. The recording is `demo/anti-radar-portfolio-demo.mp4`: a silent cut at 1920×1080 with captions, 2:38 long. It was made against the Nov 6, 2026 data with `TOUR=portfolio BASE_URL=http://localhost:3010 e2e/record-demo.sh`.

The tour picks everything at runtime from the API, so nothing is hard-coded:

- **Company:** the highest-ranked Needs Attention company with at least three material or watch events, including a competitor's event and a material one.
- **Event:** that company's first material event.
- **Comp:** the comp behind that event. If the event is the company's own, it is the comp with the most events in the window.
- **Diligence handoff:** the Needs Attention card whose suggested action is RUN DILIGENCE, the company's own event that prompted it, and the diligence claim stating it (same source URL, else the first performance claim).
- **Agent:** PORTFOLIO ANALYST in the agents table, then its failure ledger.

On other data the names and numbers change. Read the caption in the presenter bar for each scene and swap them in. Every number below was on screen in this take.

Things to say if asked:

- **Public data only.** These are publicly disclosed Anti Fund portfolio companies, as listed on antifund.com. Ownership, cost basis, marks and other private fields are never stored or shown in public mode. Stage and year are copied exactly as the public source states them, and unknowns stay UNKNOWN.
- **No language model classifies anything.** Event types, materiality (rules M1–M11), Needs Attention and suggested actions come from documented, deterministic rules. "What this could mean" and "why it matters" are labelled inference.
- **The system never suggests contacting a founder.** There are six actions: REVIEW, MONITOR, UPDATE COMPETITIVE MAP, RUN DILIGENCE, PREPARE FOUNDER QUESTIONS and NO ACTION.
- **The tour does not run diligence.** It opens the workspace from the last diligence run. On a writable live backend, the handoff button runs diligence tied to the triggering event.
- **Human steps are never invented.** Nothing on the snapshot has been reviewed, so the decision trace shows human steps as "awaiting review".
